## Manual review

1. Check the sidecar checksum, then extract the complete ZIP into a new folder.
2. Launch EasierCpp-Gui.exe. Check the title, Settings version, both themes and
   public Tools actions.
3. Create a disposable project, build/run both configurations, then add a linked
   implementation under src/. Rename it and build again with Auto Run enabled.
4. Open a copy of an existing project. Inspect its configuration, assets, libraries,
   working directory and runtime behavior.
5. Close the old version before upgrading. Keep existing projects, settings and
   caches. The Microsoft Visual C++ x64 runtime and installed build tools remain
   external prerequisites.
