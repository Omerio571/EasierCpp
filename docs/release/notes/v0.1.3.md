# EasierCpp v0.1.3 - UI Overhaul

## What's new

- One sidebar for Home, Workspace, Libraries, Project, Tools, and Settings.
- A console-first Workspace with the active target, build configuration, Auto Run,
  and interactive program input.
- Project, library, and preference editors that open within their parent pages.
  Library Manager separates managed, detected, and available libraries and adds search.
- Updated vector branding and Windows icons.

## Fixes

- Both consoles follow Light and Dark themes and retain output when the theme changes.
- Workspace information buttons support mouse and keyboard help.
- Switching sections prompts before discarding unsaved edits. Library change previews
  and execution approvals remain in place.

## Packaging

The Windows x64 ZIP includes the GUI, CLI, branding, and runtime support files.
The source regression runner stays in Development builds. Doctor, Build Errors,
Clean and Rebuild, and Optimize Workers are available in the public build.
Existing project configurations, library records, caches, and Auto Run build trees
carry forward. This release retains the existing incremental build and replacement
pipeline.

## Install or upgrade

Close EasierCpp and extract the complete ZIP to a new folder. Launch
`EasierCpp-Gui.exe` from that folder. Keep the companion CLI and `resources`
directory beside it. Keep your existing projects and manager data. See the included
`README.md` for prerequisites and upgrade details.

## Compatibility and limitations

- Targets Windows 11 x64. The Microsoft Visual C++ x64 Redistributable is a separate
  prerequisite when missing. Compiling user projects requires an installed C++
  toolchain, Windows SDK, CMake, and Ninja or a compatible project generator.
- Compatibility checks may be inconclusive for some libraries. Remote sources
  require network access and verification before integration.
- Auto Run restarts the application. Supported window placement can be restored.
  Application memory and game state are recreated on launch.
