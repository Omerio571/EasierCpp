# EasierCpp v0.1.5

Fixed an Auto Run linker error that could occur after replacing source and header
folders with files that kept their old timestamps. EasierCpp refreshes the affected
Ninja build tree when needed and continues to build ordinary edits incrementally.
This addresses [issue #2](https://github.com/Omerio571/EasierCpp/issues/2) and
[issue #3](https://github.com/Omerio571/EasierCpp/issues/3).

Older build trees may need one clean build to establish their source baseline.
Extract the complete Windows x64 ZIP and launch `EasierCpp-Gui.exe`. Keep the
companion executable and resources folder beside it.
