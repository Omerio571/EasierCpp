# EasierCpp v0.1.4 - Fixes

This fixes update follows the v0.1.3 UI Overhaul.

## What's Fixed

- [Issue #1](https://github.com/Omerio571/EasierCpp/issues/1). New standard projects
  automatically discover .cpp, .cc, .cxx and .c implementations under src/,
  including nested directories. Added, renamed and removed files are reflected
  by subsequent builds and Auto Run.
- Build outputs and dependency directories are excluded from source discovery.
  Existing imported projects retain their own source configuration.

## What's Improved

- New projects include a shared .gitignore, named README, include/ and assets/,
  with C++20 configuration and independent CMake build instructions.
- Advanced users can select manual source lists with EASIERCPP_AUTO_SOURCES=OFF.
- Test infrastructure now verifies the actual packaged public GUI. Optional
  performance runs are separate, and duplicate historical evidence was cleaned up.
- Project-generation and maintenance standards document these defaults.

## Installation

Extract the complete EasierCpp-v0.1.4-win-x64.zip into a new folder and launch
EasierCpp-Gui.exe. Keep EasierCpp.exe and resources/ beside it.
Close the old version before upgrading and keep existing projects and manager data.

Windows 11 x64 and the Microsoft Visual C++ x64 runtime are required. Building
projects requires an installed supported compiler, Windows SDK, CMake and Ninja
or the project's supported generator. See the included README for setup details.

## Known Issues

- Automatic discovery applies to newly generated standard projects. Existing
  projects are not automatically converted.
- CMake checks the source list on each build. Ninja and Visual Studio 2022 are
  tested; other generators may have limitations. An unchanged Run may perform
  a conservative no-op build. Manual source management remains available.
