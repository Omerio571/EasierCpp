# EasierCpp v0.1.1 verification

This records the completed window-controls candidate. For the combined window and
automatic-initial-run release, see [the final verification report](V0.1.1_FINAL_VERIFICATION.md).

## Implementation

The existing Win32/CMake services remain in use. Settings → Preferences now exposes
two independent native checkboxes: Keep Window Position (When Restarted), default ON,
and Keep Window Size (When Restarted), default OFF. Settings are per project in the
manager workspace; user source/CMake files and FarmGame were not edited.

Move-only restoration uses SWP_NOSIZE. Resize-only restoration uses SWP_NOMOVE and
the current monitor/DPI. Full placement keeps the previous supported maximization
behavior. Partial restoration leaves maximized/minimized/fullscreen startup state
to the application. Existing early Seamless positioning, readiness checks, A/B
isolation, build failure retention, input/output and graceful process handling remain.
Restoration choices are sampled for each launch; normal running geometry is not
continuously forced. Existing stable geometry sampling and flush behavior are reused.

The existing settings prefix remains readable, followed by geometry-v1 and the two
flags. Legacy OFF migrates to both OFF; full restoration ON migrates to both ON.
Legacy Session is upgraded to persistent retention because the new UI has no separate
session mode. Existing UTF-16 geometry records remain compatible and are retained.
Damaged appended options disable restoration; invalid geometry records are ignored.

CMake PROJECT_VERSION is 0.1.1 and supplies the CLI, GUI title and Windows resources.
No separate About dialog existed; the actual GUI title now displays the version.

## Manual acceptance and limits

Follow [the numbered acceptance guide](../development/WINDOW_MANAGEMENT.md).
Tests use disposable Win32 and approved pinned Raylib fixtures. SDL/SFML live
applications and physical multi-monitor/mixed-DPI configurations require manual
acceptance; synthetic DPI conversion and disconnected-monitor fallback are tested.
Fullscreen/exclusive-resource applications may need Safe Replacement. Geometry
restoration does not restore game state, process memory or Windows Snap Groups.
Apps that force geometry after startup can override the manager's initial placement.

The portable ZIP does not bundle a compiler or Microsoft runtime. It needs Windows
11 x64 and the supported MSVC runtime; compiling projects requires an installed
supported C++ toolchain. No installer, permanent PATH change, commit, tag, push or
GitHub Release publication is performed.
