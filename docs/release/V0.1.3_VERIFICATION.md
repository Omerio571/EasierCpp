## Extracted package results

The archive checksum matched its sidecar. The final ZIP was extracted to a fresh
temporary path with spaces outside the checkout. The packaged CLI reported
0.1.3, discovered Visual Studio tools from ordinary PowerShell, created a
multi-file project, and built and ran it in Debug and Release.

The packaged GUI smoke passed in 26.38 s. It checked the caption and live icon,
absence of both internal test controls, presence of Doctor and Optimize Workers,
both themes and Workspace help, inline project and library forms, a disposable
header-only library pin, preference persistence across restart, interactive
input, Auto Run after a source edit, Stop, and shutdown.

The first smoke exposed a source-script reference in Doctor and a missing test
profile flag in the launcher. The Doctor reference was corrected and the native
harness now sets its own test flag. The earlier launcher selected Light in the
regular GUI preference profile. The prior theme was unknown and was left as-is
after that change. The final rerun used a disposable profile.

Complete the manual checks in the packaged README before publication. Check
physical DPI transitions and taskbar branding, a second Windows 11 x64 machine,
and an upgrade using a backup or isolated copy of real v0.1.2 data. The local
migration fixtures cover representative formats. Live library services and a
separate performance benchmark are outside the release smoke test.
